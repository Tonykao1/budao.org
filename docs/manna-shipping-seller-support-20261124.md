## 经营主体（建议最简方式）
采用用户已有的中国大陆有限公司做**唯一销售合同、收款、发票与售后责任主体**，使用 MANNA / 买拿为商店品牌名。不能凭品牌名称假装注册公司。正式开售前必须核实营业执照真实完整名称、统一社会信用代码、经营范围及与实际服装销售相关的登记要求，按实际销售地区公示有效经营者信息及售后联系方式。未完成前，页面只能标注拟由既有有限公司承担，不能声称已经具备具体主体资格。

## 客服适配器（不是已经接通的聊天系统）
- `manna-support` 是前台可见的咨询入口；未配置时只说明“实时客服通道正在接入”，**不接收消息、不存储姓名地址、不显示虚假的在线状态**。
- 未来可用 tawk.to 的正式 Property ID、Widget ID，分别填入商品页 `#manna-support-panel` 的 `data-chat-property` 和 `data-chat-widget`。两个 ID 经正式客服账户管理员确认后方可写入；不可使用演示或他人的 ID。
- 单击开始实时对话后才从 `embed.tawk.to` 加载第三方聊天脚本。必须在上线前核对客服值守、用户隐私告知、敏感信息处理、跨境数据传输及公司业务要求。
- 当服务未开通或第三方服务失败时明确告知，不作“在线客服正在回复”等不实承诺。
- 后续须扩展到所有商品共用的正式经营者与客服中心；本次仅对首款产品试验接口。
