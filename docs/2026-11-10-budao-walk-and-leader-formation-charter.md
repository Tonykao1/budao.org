# BUDAO 同行实践与带领人造就总纲（审阅稿 v0.1）

> 日期：2026-11-10  
> 性质：**内部事工与课程设计总纲／待审核**，非已发布培训教材、非网站新功能指令。  
> 核心来源：现有首页、同道历史模板与交互流程，以及网站已确认的五板块使命。  
> 所属关系：BUDAO GLOBAL 跨文化事工内容；不改变中文网站、设计、美术、现行流程或发布权限。

## 一、为何写这份总纲

这份总纲要回答三个问题，同时严格区分“已经公开呈现”“已有实践资料”“下一阶段筹备”。

1. **为什么同行？** 信仰根基与同行理念，以[首页](../home.html)已确认的表达为权威文本。
2. **怎样同行？** 以[同道历史模板](../tongdao-data.js)及[现行引导程序](../tongdao-app.js)为可核对的实践来源，归纳常见步骤；不把某个旧模板升格为跨地区的唯一范式。
3. **如何装备同行者？** 为**未来带领人造就视频**与**52 周灵修栽培计划**提供分工、内容结构与审核标准。这两项尚未在网站正式发布。

**使命边界：** BUDAO 以基督为信仰根基，通过自然中的行走、真实的人际相遇、故事、圣经和祷告，为人创造同行及回应福音的机会。步道活动不是圣礼，不构成得救条件，也不替代地方教会的崇拜、门训与牧养。对来访者不以宗教身份设参与门槛，不使用隐瞒宗教目的、施压决志或交换服务等方式开展邀请。

## 二、信仰根基：只从真实首页出发

### 2.1 当前首页的三个问题

- **我们在做什么？**「健行于天地，相知于彼此，在旷野经历与祂的同在。」
- **为什么是『步道』？**「祂就是道路、真理、生命。唯有祂亲自感动你同行天路，共步主道。」
- **『步道』有什么？**「一个拥抱、一条线路、一则故事、一段经文、一起祷告。」

首页宣言「余生行走，不偏左右」及已审定的英文诗句，以[官方翻译规范](./2026-11-09-global-translation-charter.md)为准；本总纲**不修改、不重译**。

### 2.2 应如何解释，而不是误读

- **以基督为中心。**「道路、真理、生命」指向约翰福音 14:6 的基督，而不意味着某一条户外路线本身具有救赎效力。
- **以真实同行为方法。** 行走帮助人面对面地倾听、彼此认识；自然是受造界与相遇场所，不是神本身，也不是属灵成效的保证。
- **以圣经为分辨尺度。** 绘本和经历是进入话题的途径，不能凌驾于经文上下文与正统基督教教导之上。
- **以邻舍之爱接待。** 真实相遇重于观看次数、表单数量或线上数据；邀请要公开、诚实、尊重个人意愿与自由。
- **以真实教会为归属关系。** 需要长期牧养、洗礼、圣餐及教义教导的事务，应与合适的地方教会及牧者建立负责的关系；数字引导不能代替这些责任。

### 2.3 「五个一」与方法的关系

「一个拥抱」不是强制身体接触，「一条线路」不限定长度或难度，「一则故事」不限定必须某一本绘本，「一段经文」必须被忠实解释，「一起祷告」须尊重参与者是否愿意参与。

这些是**首页表达的五项体验意象**，不是完成活动的五项硬性考核。是否、何时、以何种方式分享信仰，应当根据活动清晰告知、参与者意愿和负责的带领判断。尤其不得把身体接触、个人披露或公开祷告作为参加门槛。

## 三、从现有「同道」归纳一次同行（实践原型）

> 来源：[tongdao-app.js](../tongdao-app.js) 的当前交互状态机及 [tongdao-data.js](../tongdao-data.js) 的主题资料。本节**描述现有程序的顺序**，尚未为全球教会制订标准礼序。

| 顺序 | 现有程序阶段 | 目的与带领人观察要点 |
|---|---|---|
| 0 | **预备 / initialize** | 确认时间、人数、地点、天气与安全承诺；可选择自然分组或系统提供的分组模式。真实线路还须由人核查风险及参加者能力 |
| 1 | **欢迎 / welcome** | 明确今天为什么相聚，尊重不同背景；网页是辅助，不能取代真实带领人与彼此关系 |
| 2 | **三问破冰 / icebreaker** | 每人有被认识的机会，不要求回答超出意愿的私人问题 |
| 3 | **热身 / warmup** | 以现有七步热身为原型，视能力、伤病与环境调整，必要时跳过 |
| 4 | **祷告 / prayer** | 现有「摩西祷告」引导约一分钟；在跨文化环境中须先清楚告知，参加与否不受强迫，动作也可调整 |
| 5 | **分组、同行与分享 / groups + walk** | 现有模板使用五轮分享题；以轮流讲述、认真倾听为主，不逼迫解释、纠正或提供答案 |
| 6 | **故事 / story + storyQuiet** | 观看、朗读或讲述一个与主题有关的故事，随后保留安静；使用绘本或音视频须核验授权 |
| 7 | **圣言 / word + wordQuiet + wordAgain** | 经文先读、安静，再由另一人重读；带领人应预备经文出处、上下文与合宜解释 |
| 8 | **回应 / respond** | 现有模板的第六题引导联系道路、故事、经文和生命；不是测验，也不应推定所有人有相同领受 |
| 9 | **继续前行 / go** | 第七题转向生活中的具体一步；分享内容不自动成为可公开的见证 |
| 10 | **祝福 / blessing + hug** | 可彼此祷告、祝福或祝平安；现有程序明确允许用握手、点头或话语代替拥抱，任何接触须先征得同意 |
| 11 | **结束祷告 / closingPrayer** | 邀请愿意的人祷告，并为结束及返程作清楚安排 |
| 12 | **本周成长 / grow** | 每套历史模板附有一项本周实践挑战；若有后续关怀，应由负责的同工和地方教会承接 |

**程序细节≠神学规范：** 当前程序在部分分享轮次中预设 8 分钟计时；存在独行模式、2–3 人共同分享、较多人重新分组的逻辑，也含「同性分组」选项。这些都是当前产品实现，不意味着每次活动必须按相同时间、性别分组或动作完成。任何此类模式进入国际培训前，须经过适用文化、可及性、反歧视、参加者舒适度与安全审查。

### 3.1 哪些可以作为 BUDAO 的恒常原则（**候选，待审**）

1. **忠于基督与圣经**，不因追求体验而牺牲经文原意。
2. **先有人、后有流程**：安全与关怀高于卡点、计时及完成率。
3. **倾听胜过说服**：分享自由、保护隐私，不强迫见证或属灵表态。
4. **真诚的邀请与回应**：活动身份、信仰元素与用途必须事先透明。
5. **回到生活与群体**：一次同行之后应有可选择的真实联系、实践及合宜的牧养转介。

这些是为课程提炼的候选原则，**不是已由 BUDAO 正式通过的五条教义条款**。

### 3.2 哪些应留给地方教会及带领人调整

- 线路长度、地形、时间、人数、室内替代方案和天气预案。
- 绘本、故事及艺术媒介选择；不同地区对版权和文化表述的要求。
- 破冰题目、个人分享深度、语言和翻译方式。
- 读经译本与教义释经背景；不能以机器翻译替代圣经版本许可和审阅。
- 是否配对、如何分组、是否热身、姿势与安静时长。
- 是否安排公开祷告、祝福、握手或拥抱，必须尊重参加者选择与当地文化。
- 与哪一间地方教会建立长期牧养合作，以及活动后是否邀请继续同行。

### 5.1 装备视频最低交付标准（提案）

每个视频/单元预留：学习目标、适用人群、依据的首页或历史模板、圣经索引、真实案例或示范、情境练习、讨论与反思问题、字幕和逐字稿、版权与伦理审核记录。

完成观看 ≠ 自动成为 BUDAO 认可的带领人 ≠ 获得网站发布权限。真实带领或平台授权仍按既有的同行实践、组织认可及安全责任机制分别处理，**本总纲不授权任何角色或权限更改**。

## 六、52 周灵修栽培计划：与视频不同的第二条装备路径

**当前状态：用户已明确计划建立 52 周灵修栽培；课程周目及正式教材均未完成。**

### 6.1 两个项目不能混为一谈

- **带领人视频**：关注如何服事别人——知识、方法、伦理、风险、带领与地方教会合作。
- **52 周灵修栽培**：关注生命如何在基督里持续成长——圣经认识、祷告、悔改、信心、品格、群体相爱及实践。

两者可以共享经文和实践案例，但不能把完成 52 周视为获得带领资格，也不能把带领人训练简化为一套灵修打卡。

### 6.2 52 周分期骨架（**供审核的建议，不是已批准大纲**）

| 建议阶段 | 周数 | 方向（仅为主题领域，不是预写 52 个标题） |
|---|---|---|
| 第一阶段 | 1–13 | 福音与生命根基：神是谁、基督的工作、圣经、恩典、信与回应 |
| 第二阶段 | 14–26 | 跟随基督的日常：祷告、读经、悔改、盼望、节制与信实 |
| 第三阶段 | 27–39 | 在群体中成长：敬拜、教会、彼此承担、宽恕、恩赐与邻舍之爱 |
| 第四阶段 | 40–52 | 走入世界的见证：日常职业、家庭、社会关怀、同行、服事与持续成长 |

这四段只是便于讨论的 **13×4 结构提议**。每周经文、神学前提、学习负担及适用群体须另行研议，并通过审核，**不将现有十个同道主题直接拼接、扩写成 52 周**。

### 6.3 单周内容建议模板

1. **本周经文**：准确书卷章句与授权译本；提供上下文，不断章取义。
2. **研读观察**：原文讲什么？对象、语境和经文主要信息是什么？
3. **基督与福音关联**：避免泛道德主义，也不任意把每句经文寓言化。
4. **个人默想与祷告**：允许安静、自省，不强制公开私人生活。
5. **真实同行或服务实践**：一件自愿、具体、可行的邻舍行动。
6. **群体分享与关怀**：在适当的教会或团契关系中进行，遵守保密约定。
7. **带领人注意事项**：关于文化、年龄、神学难点、安全和求助的提示。
8. **反馈与修订**：不以属灵打卡次数评判信心深浅。

## 七、跨文化、安全与神学审核的不可省略事项

### 7.1 生命与身体安全

开始之前应针对当地路线、交通、天气、强度、手机使用、集合与散场、通讯和紧急情况完成风险评估。现有程序的“行进中不看手机”承诺值得保留为安全提醒，却**不足以替代完整的现场安全计划**。弱势参与者、残障人士、长者及未成年人需要额外的适配、监护与保护措施。

### 7.2 自由、同意与私密

活动应事先明确其基督教背景和祷告/经文环节。倾听与分享以自愿为本，不要求参加者当众暴露创伤、病情、家庭秘密或宗教身份；不以祝福、拥抱或祷告作为服务交换条件。摄影、语音、评论、见证与资料保存按可理解的告知和相关法律要求取得适当许可。对未成年人实施更严格保护。

### 7.3 教会问责与能力边界

BUDAO 带领人不等同于受按立牧者、医生、治疗师或法律顾问；对危机或严重困扰应按当地保护规范转介合适专业人员，并与地方教会建立负责的牧养关系。跨地区传播方法不意味着 BUDAO 要统一支配各地教会。

### 7.4 文字、图片与圣经版权

绘本故事、影音和圣经译本存在不同授权范围。视频示范或英语材料涉及相关内容时，逐件核查公有领域、许可、引述比例与使用地域。AI 翻译输出不自动解决版权授权、神学准确性和文化适切性。

### 7.5 文化适配而不稀释福音

语言可以变化，表达方式可以调整；基督中心、经文忠实、人与人真实相遇、尊严和同意不能因追求传播效果而被舍弃。不得将某一中国文化语境中的表情、肢体接触、分组或集体祷告习惯机械套用于所有国家。

## 八、开发与内容制作次序（建议）

**A｜确认总纲。** 由事工负责人核实第二节对首页的解释与第三节的“原则/可调整项”划分；分别送交神学与安全审核，注明争议。

**B｜整理母版素材。** 为现有十套同道模板建立有来源的只读索引；逐个审读经文上下文、绘本及视频使用权。先从一套真实案例做完整示范，不先批量翻译。

**C｜试做一份带领人视频脚本。** 与一份相应的演练/讨论指引配套，实地观察对初次带领者是否足够清晰。

**D｜讨论 52 周规划。** 先确定对象、教义审核人与分期理念，再制作第一阶段的少量试点周内容，验证可坚持的节奏后才扩展。

**E｜跨文化试点。** 邀请合适的海外教会、带领人与不同语言使用者评阅，收集实际问题；以真实关系、带领实践和牧养连接评价，而非点击流量。

**F｜形成公共国际版。** 内容、权限、版权、隐私、视频字幕、可及性与视觉回归达到标准后再上线。未完成阶段不放“立即报名”“课程已开放”“认证带领人”等误导性按钮。

## 九、审阅问题／待决事项

1. 首页以外，是否需要由教会或神学顾问审核一份单独、简明的 BUDAO 信仰告白？现阶段**不默认新增**。
2. 从“同行模板”抽象出“带领人必修方法”时，哪些阶段绝不可遗漏？这需要真实实践者确认，不由软件程序自动决定。
3. 安全、文化、隐私和未成年人事工的最终审稿与负责机制由谁承担？
