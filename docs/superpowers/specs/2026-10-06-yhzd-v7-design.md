# 萤火之地 V7 设计规格

日期：2026-10-06

## 1. 设计目标

将现有“随机内容场”重构为顶级图文网站式的 editorial narrative 页面：先建立阅读秩序，再保留随机性与“还有很多”的感觉。

核心原则：

> 一屏一见，一次一物。

用户每次进入页面时，首先应知道看哪里、读什么；图像完整可看，文字完整可读。随机性只改变内容，不改变版式秩序。

## 2. 固定命名与语气

- 页面正式名称统一为「萤火之地」，不得再出现「营火之地」。
- 副句固定为：
  - 有些话，
  - 只有走过的人才会说出来。
- 顶部仍保留「✦ 路上星火」入口。
- 页面语气保持安静、克制、记忆感，不做活动总结、成果展示或相册墙。

## 3. 首屏信息架构

### 3.1 顶部导航

沿用现有站点导航视觉与链接，不在 V7 中新增新的品牌功能按钮。

效果图中的“分享你的故事”按钮仅作为视觉草图元素，V7 首版不实现。

### 3.2 标题区

首屏上半部只允许出现：

- 「✦ 路上星火」
- 「萤火之地」
- 固定副句

标题区为绝对静区：

- 不出现参与者语句
- 不出现图片
- 不出现浮动残片
- 不允许任何内容遮挡标题

推荐占首屏高度约 30–36%。

### 3.3 第一幕主内容

标题区下方进入第一组内容：

- 一张完整主图
- 一条完整主引语

桌面端采用非对称双栏：

- 主图宽约 55–62vw，保持完整比例显示，不裁切主体
- 引语占约 22–28vw
- 图与文字之间保留显著负空间
- 图文可同时出现，但不得发生遮挡或视觉粘连

主图与引语来自各自独立随机池，不建立语义配对。

## 4. 后续内容节奏

V7 不再把多张图和多段话同时撒在一张大画布上，而改为连续的 editorial sections。

建议节奏：

1. 第一幕：大图左 / 主引语右
2. 第二幕：主文字左 / 中图右
3. 第三幕：中图左 / 短句右
4. 第四幕：留白更大，单独一条话成为主角
5. 后续继续交替，不形成固定模板墙

每一幕只承担一个主要视觉任务。

原则：

- 图完整
- 字完整
- 一幕最多 1 张主图 + 1 条主文字
- 可有极少量次级内容，但不得抢主次
- 不允许图压图、字压图、图压字

## 5. 图片层级系统

只保留三档图片层级：

### A. 主图

- 页面核心视觉
- 桌面宽度约 55–62vw
- 完整显示，不 crop 成装饰片段
- 圆角 4–8px
- 极弱暖黑投影

### B. 辅图

- 宽度约 28–38vw
- 出现在后续 section 中
- 不与主图同时抢首屏中心

### C. 远处提示图

- 仅用于暗示“还有”
- 可在边缘轻微露出，但不得成为首屏阅读障碍
- 不承担信息获取任务

V7 首版不使用大量不同尺寸、不同角度的小图片拼贴。

## 6. 文字层级系统

仅保留三档文字：

### A. 主引语

- 30–42px（桌面，视 viewport 调整）
- 行距约 1.55–1.7
- 100% 可读
- 每一幕最多一条

### B. 普通引语

- 22–30px
- 用于后续 section
- 不与图片重叠

### C. 来源说明

- 「— 一次同行之后」
- 10–12px
- 低对比但必须仍可辨认

不允许通过过低 opacity 制造“远景文字”。文字无论处于何处，都必须可阅读。

## 7. 随机机制

保留现有大池随机逻辑，但改变随机作用位置。

### 7.1 图片

- 图片池可持续扩展至 30–50+ 张
- 每次加载只抽取少量图片用于本次页面
- 同一次加载不重复
- 优先避开近期已看图片
- 近期历史仍使用本地 localStorage，无 IP 跟踪

### 7.2 文字

- 文字池继续独立随机
- 图片与文字永远不配对
- 长短句按 section 容量选择，但不改变 section 结构

### 7.3 固定骨架，随机内容

核心规则：

> 随机的是内容，不是构图。

页面刷新后，主图、辅图、引语会变化，但视觉骨架保持稳定。

## 8. “无有穷尽”的表达方式

V7 不再通过“首屏很多内容”制造丰富感。

改用：

- 后续 section 的持续展开
- 屏幕边缘极轻的内容预告
- 用户继续向下或轻微横向探索后遇见更多内容
- 刷新后重新组合内容

无限感来自“还有”，而不是“眼前很多”。

## 9. Z 轴与空间感

Z 轴降为辅助，不再承担构图职责。

允许：

- 1–2° 极轻透视
- 极轻暖黑投影
- 非常弱的视差

禁止：

- 夸张 3D 卡片
- 多图层叠
- 依赖遮挡制造空间
- 让用户明显意识到页面在“做 3D”

用户应只感受到空气与距离，不应感受到特效。

## 10. 交互

V7 首版以纵向阅读为主。

- 鼠标滚轮、触控板垂直滚动为主要阅读方式
- 不用轮播箭头作为核心导航
- 原有横向漫游机制不进入首屏主叙事，可保留为后续探索候选，但不在 V7 首版强制实现
- 页面不做自动轮播

效果图中的左右箭头仅为视觉参考，不进入 V7 首版。

## 11. 响应式

### 桌面

- 保留非对称双栏与大面积留白
- 重点确保 1440–1728px 宽度下的节奏

### 平板

- 降低双栏比例差异
- 主图仍保持完整

### 手机

- 改为单列 editorial flow
- 标题 → 主图 → 引语 → 下一组
- 图片 100% 宽度或 88–92vw
- 禁止将图片隐藏；移动端也必须能看到真实历史照片

## 12. 性能与图片质量

- 正式预览必须使用真实 480/960 WebP，不得再用 120px 临时预览图放大
- 主图优先加载 960 版本
- 非首屏图片 lazy load
- 不做高成本滤镜动画

## 13. 无障碍与可读性

- 所有正文保证足够对比度
- 不通过 opacity 将正文降到不可读
- 保持键盘与滚动基本可用性
- 装饰图片可使用空 alt；若后续加入可识别的历史说明，则再补充语义 alt
- `prefers-reduced-motion` 下关闭所有非必要动效

## 14. 现有代码复用与重构边界

复用：

- 现有导航
- 星点背景与暖色 glow，可适当弱化
- 图片 manifest 与随机图片池
- 文字池
- localStorage 近期历史机制

重构：

- 删除当前绝对定位的 `.image-slot-*` / `.message-*` 大画布布局
- 改为 section-based editorial flow
- 不再通过多个绝对坐标 slot 组织首屏内容

## 15. 验收标准

V7 只有同时满足以下条件才通过：

1. 第一眼明确知道先看标题，再看主图，再读主引语
2. 首屏主图完整可看，不被裁坏或遮挡
3. 首屏主引语完整可读，不与图片重叠
4. 页面不存在图压图、字压图、图压字
5. 每一幕都有明确主次
6. 刷新后内容变化，但页面依旧稳定、美观
7. 仍能感受到“后面还有很多”，但首屏不拥挤
8. 手机端同样可看图片、可读文字
9. 正式预览使用 480/960 清晰资产
10. 主站 main 在明确验收前保持不变

## 16. 首版不做

以下内容暂不进入 V7 首版：

- 分享按钮
- 轮播箭头
- 自动轮播
- 复杂 3D
- 强横向漫游
- 图片与文字语义配对
- 活动标签、时间、地点、相册说明
- 点赞、评论、收藏

这些功能只有在 V7 阅读秩序稳定后才单独评估。
