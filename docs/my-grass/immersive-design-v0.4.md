# 我的牧草 · 沉浸式古卷 V0.4（2026-09-29）

本设计延续 [产品及服侍档案 V0.3](./product-archive-v0.3.md)。仍然只有三阶段：**读经｜领受、默想｜沉淀、分享｜牧养**，没有独立的「成言」页。

## 本轮决议
- 从原先约 1280×640 的嵌入式书卷扩展为约占桌面视口宽度 96%、高度 92% 的独立沉浸空间；牧场在打开书卷时退入深色背景，外层统一返回按钮保持可用。
- 采用**双页**而非三张常驻页面：领受（左经文，右本人朗读）；沉淀（左刚读的经文，右个人笔记）；牧养（左默想母本，右不超过80字的私人微分享）。移动端采用一页式纵向阅读，不强行把两栏缩小。
- 三个阶段顶部仅保留「领受／沉淀／牧养」；删掉重复的产品解释与功能宣言，把阅读空间留给经文和用户自己的话。主要输入至少16px，主要按钮尽量达到43–45px。
- 以原生 Canvas 像素工笔**重新绘制适配视口长宽比**的羊皮古卷：粗糙阶梯纸边、双页中缝、缝线、纤维颗粒、局部色差和克制的叶纹。保留牧场和其他功能区既有视觉，不对原图作强行拉伸。
- 恢复旧版的「经文定位」：旧约39卷、新约27卷、书卷及章（上限按各书卷）、节起止及整章选择。导航**只定位出处**，没有接入带授权的全文圣经译本；用户在阅读页输入或粘贴实际所用的经文，自己核对文字与原声。
- 保护已有记录：当前有尚未正式保存的经文、默想或原声时，不允许直接切换经文并覆盖；从已保存的旧经文切换时新开一页，旧档仍留存。

## 本期非目标
- 不上线语音模型训练、合成音色、云端同步与对外自动公开。
- 不改动数字牧场其他模块、不切换 budao.org 主分支。
- 不为了做大古卷而牺牲实际朗读、保存、回听、导出、母本/微分享数据关系。
