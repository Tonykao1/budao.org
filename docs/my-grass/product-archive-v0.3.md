# 我的牧草 · 产品及服侍档案 V0.3
> 2026-09-29 · Tony × Sky · 作为本阶段唯一的产品开发依据；未获明确同意，不更动已批准的牧场景观和像素羊皮卷视觉。

## 一句话定位
**一生的灵修与牧养成长档案。**

**愿景：** 让神的话进入生命，让生命留下声音，让真实领受成为他人的牧草。每个人先被牧养，继而有机会凭真实见证、劝勉、关怀和同行，成为他人的祝福。普遍的彼此关怀不等同于教会正式牧者、教师的职分；数字产品不自行认证牧者资格。

## 仅有三个主阶段
1. **读经｜领受。** 保存准确的圣经引用、译本/来源信息、经文文字以及用户**亲自朗读**的原始音频。文字稿与最终原声一一关联，可供日后回听和用户自愿授权后的个人语音研究。此处不默认取得声音训练权。
2. **默想｜沉淀。** 用户写个人灵修笔记，原始笔记保留为不可由生成模型偷偷改写的母本；未来经过专门授权可将笔记转化为个人专属模型合成的声音，**无需重新录制笔记**。必须区分原声和合成声音。保留经文重逢、未完祷告及长期回顾的扩展空间。
3. **分享｜牧养。** 核心是极短的**微分享**：一句真实领受或一小段声音；应当由用户亲自审阅、主动选择是否公开。与原始经文、原声及母本笔记保持出处关联。经年累月，作品按书卷、经文、时间及主题自然生长为个人牧养体系，而非碎片化 feed。可以关怀与同行，但不鼓励未经确认的教导或替他人擅自发言。

**不开发独立的「成言｜整理」模块。** 整理或转音频将来属于第二、三阶段的辅助能力，不应强迫用户成为内容生产者。

## 与众不同的服务切入点
- **一段经文，一份文字，一段本人原声，一份真实回应。** 保留文字与音频的来源、日期、版本和对应关系。
- **微牧养，不是微讲道流水线。** 微分享可以只是一句话，绝不以播放量、发稿量或连续打卡天数给属灵成熟度评分。
- **经文重逢。** 同一经文与不同生命阶段的笔记自然关联；用户主动回顾，不使用夸张的算法刺激。
- **个人声音资产。** 原始录音应被保存为可独立导出、可由持有者管理的资产。训练个性化声音、生成私用音频、对外公开音频分别征得单独明确授权，必须可以撤回将来用途；绝不默认用户的声音可供训练。
- **长期牧养遗产。** 私人内容默认不公开；传承或遗留授权将来单独设计。不因为用户离世便自动公开。
- **不把停留时长当作终极目标。** 产品要有足够吸引力，将人的注意力从无益的内容转向值得长久投入的阅读、祷告与关怀；也应鼓励人回到真实关系与教会生活。

## V0.1 第一阶段实际开发范围
- 在已批准的像素双页羊皮卷内，提供三阶段的实际可操作界面。
- 经文出处、译本标注和用户输入的经文文字；现阶段**不伪称已接入授权全文圣经服务**。
- 经用户主动授权调取麦克风，保存本人朗读的原始音频；输入的经文文字与录音关联，用户负责核对准确性。
- 个人默想文字保存；允许非常简短，也不阻碍长篇笔记。
- 从本人笔记手动摘出不超过 80 字的「一粒牧草」微分享，用户可修改、审核，默认保留为私人作品草稿；不自动对外发布。
- 在同一条记录上维护 scripture / reading_audio / reflection / micro_share 的来源关联；可按经文与日期回看。
- V0.1 本地预览使用浏览器 localStorage (文字) 和 IndexedDB (音频)，标记为本机演示而不是已具备云端、端到端加密、多人同步或正式发行。
- 专属声音模型、训练、AI 合成笔记音频、公共分享/牧养推荐、全文译本接入、长期传承授权：**接口先预留，不可假装现已可用。**

## 不可逾越的边界
1. 圣经文本、用户笔记、AI 辅助内容应当可辨识；AI 不以神的口吻为个人宣告旨意。
2. 原始朗读、合成语音、分享权限三者相互独立；不得凭录音行为推定用户允许克隆其声音。
3. 公开内容须经过本人审核、主动发布；不得泄露笔记中出现的第三方隐私。
4. 完整的读经与默想流程不依赖 AI；不能以打卡和内容产量量化敬虔。
5. 不触碰 budao.org 正式站点和数字牧场其他七个既定功能区的已批准视觉。

## 稳定的数据实体草案
- `grass_entry`: id, date, scripture{reference,text,translation,source}, readingAudioId?, readingVerified?, reflection, timestamps.
- `reading_audio`: blobId, mimeType, duration?, size, createdAt, explicitConsentForRecording; **不含默认训练授权**。
- `micro_grass`: id, entryId, excerpt (<=80 Unicode code points), visibility (private by default), reviewedAt?, provenance (user-edited).
- `voice_permissions`: training=false, synthesizedReflection=false, publicDistribution=false, each separate opt-in and revocable. V0.1 does not implement voice model training.

## 不把现阶段技术演示称为已上线产品
正式身份和跨设备数据持久化须在云数据库、会话授权、访问控制、备份和可删除/导出机制完成以后再单独验收。V0.1 供原版牧场内逐项审看。
