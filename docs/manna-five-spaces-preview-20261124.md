## 1. 名称与范围
- 正式英文统一：**MANNA**；中文：**买拿**；口号：「买拿买拿，连买带拿。」

- 不参考主流平台的排列、推荐、销售动机和交互模式。以五重空间叙事作为探索方向（不声称世界首创）。

## 2. 五重空间
1. **供应之门 THE GATE**：使命与自由进入；光圈和字形组成抽象空间。
2. **丰盛之桌 THE TABLE**：三个构成式概念物件、交互切换、跳转独立说明页。
3. **公平之秤 THE MEASURE**：示例价格 128 元分解为商品与制作 54、劳动 24、履约 18、售后预留 8、经营余量 24。滑杆调整劳动报酬 16–40 元，实时重算经营余量。**全部为数学演示，非财务审计、报价或利润保证。**
4. **同工之场 THE FIELD**：选品、制作、品控、整理、交付与售后六种角色模型（不涉及实际人员信息）。
5. **安息之所 THE REST**：不强迫成交的消费者权益承诺，四步交易解释弹窗，**不生成订单**。
6. **归途 THE RETURN**：回到事工使命和空间入口（结束性段落，不作为第六个主导航空间）。

## 3. 商业与属灵边界
- 基督信仰用于指导公平劳动、守约、诚实与爱邻舍，不是商业溢价、宗教消费义务或宗教背书。
- 不采用倒计时抢购、诱导勾选、模糊价格、假库存、假评论、宗教情绪施压。
- 弱势或残障劳动者不得被商品化，真实身份、案例、影像须先获得明确授权；初期采用匿名角色模型。
- 只展示**拟议**公平机制，实际售价成本和报酬分配必须有经核实的采购、账目、结算凭证。
- 步道对买拿提供使命及网站支持；销售经营主体必须另行确认。经营收入不得与奉献或牧场信息混同。

## 4. 交易功能阶段划分
- **当前实现**：无个人信息收集、无购物车、无订单、无付款、无真实 SKU；所有概念物品显式标注。
- **未来交易准入**：确定经营主体、合法资质、首批真实商品和可审计定价、服务政策、支付接入、物流库存、退款、订单安全与对账后，另开交易功能 PR 验收。
- **未来数字牧场**：只共享最小必要商业产品服务，属灵记录与支付数据隔离。

## 5. 无障碍与跨设备
采用语义 HTML、标题序列、按钮/键盘可用、aria-pressed、aria-live、原生 dialog、清晰演示标识、reduced-motion、移动端布局以及独立于主站的 CSS。Tesla 车载布局还需在实际设备上验收，不因桌面 CSS 自动认为已通过。
