# MANNA 买拿｜公开站点首发发布范围

日期：2026-11-24
发布目的：在 BUDAO 步道正式网站下开放 MANNA 公共事工及商品展示站。

## 本次纳入正式网站
- /manna/：五重空间及未开售提示
- /manna/about/：简明使命
- /manna/goods/：三件明确标为展示样品的产品页面
- /manna/goods/sample-01/ ... sample-03/：未销售样品说明
- /manna/assets/：原始透明 PNG，独立 CSS/JS
- /home.html 的页脚添加单个“MANNA · 买拿”入口，不加入六项主导航、不改“营火之地”“路上星火”的原有相邻两个链接和任何牧场、帐篷业务

## 必须维持的边界
- 未与真实供应商/库存/价格/订单/支付集成，不能宣传为可以直接下单的商城。
- 公众商品展示为演示样品；非真实商品要明确标识。
- 不发布 /manna/workbench/，因为它只是无认证、无持久化、可自由切换录入与审核模拟角色的交互原型，不能承担生产管理。
- 不合并已审查中的 MANNA feature PR #142；只从其审定静态目录摘取公共站点内容，以 main 为发布基线。
- 首页与使命页允许搜索索引，模拟商品详情保持 noindex。

## 后续条件
真实商品上线前，需独立账户/角色鉴权、后台数据存储、文件上传和服务端审核、商户资质、消费者条款及支付履约体系通过验收。不能通过浏览器端角色切换实现授权。
