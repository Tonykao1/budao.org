# MANNA 买拿｜商品工作台 V1 设计与实现边界

日期：2026-11-24
状态：**独立交互原型 / 无真实数据写入 / 未上线正式网站**
入口：`/manna/workbench/`（仅开发分支的 Vercel Preview，且不从公共商城导航暴露）

## 目标
让获授权的买拿同工通过手机或电脑，在一个简明工作台中维护商品，不再需要直接改动网站代码。

## 已实现的演示
- 左侧商品档案（手机版横向卷动）、按状态筛选、搜索、新建商品。
- 五步编辑：**商品、图片、公平、交付、流程**。
- 基础字段：名称、简介、类别、自动编号、示例售价、模拟库存、详情。
- 上传照片仅在浏览器当前页面创建 objectURL，格式白名单 JPG/PNG/WEBP；每张不超过 8 MB，总数不超过 5 张；删除和离开页面时撤销相应 objectURL。**不上传，不保留，不远程记录**。
- 价格核算：采购与制作、参与劳动报酬、物流支付、售后预留；图形分段与经营余量同步计算；成本合计超出售价时拒绝提交审核。**演示数字，不是真实财务报表**。
- 交付：供应来源、发货说明、售后方式及补充说明。
- 页面内的两种模拟角色：录入、审核。流程：草稿 → 待审核 → 批准 → 模拟发布；审核可以退回修改，已发布可模拟下架。
- 页面内即时商品预览和资料完成度、模拟操作记录。
- 初始三个**模拟记录**，其中 DEMO-001 使用抽象示意图和演示价；不代表商品库存、质检结果、销售许可、审核批准或上架。
- 原始透明 LOGO 不改像素、只按 `object-fit:contain` 显示。

## 重要：未实现的能力
- **没有认证、真实角色权限、用户账号、后台 API、数据库、存储桶、图片永久存储、服务端审核、支付、订单、真实商品发布或回写 MANNA 前台。**
- 页面上的“录入 / 审核”角色切换**不是授权**，不能用于生产环境。所有模拟状态保存在 JavaScript 内存中；刷新即重置。
- 当前不在 MANNA 对外商品页添加工作台链接；避免让消费者误入管理界面。预览页面设置 `noindex,nofollow,noarchive`。搜索引擎限制并不构成访问控制。

## 真实建设的合同边界
1. **单独建立身份与权限**：服务端认证；录入者只写草稿、审核者可审核、发布者可正式发布；高权限动作要服务端授权，不接受浏览器提交的“角色”作为可信依据。与步道活动后台、牧场读经与祷告记录隔离。
2. **服务端商品模型**：商品 ID、商户主体、SKU、名称、分类、描述、价格分、货币、真实库存、成本分项（整数分）、供应证明、图像对象键、政策快照、状态、版本及时间戳。
3. **审核与审计**：商品提交时固定不可篡改的版本快照；审核批准必须针对同一版本，变更售价或其他关键字段后重新审核。保留提交、批准、退回、上架、下架的服务端审计记录。
4. **并发与幂等**：使用商品版本号乐观锁防止多人覆盖；审核/发布以幂等键避免重复触发。通过后台 API 对价格和成本边界再次验证。
5. **媒体安全**：授权后上传原图至有私密权限和扫描/转换的对象存储；校验文件魔数、大小、图片尺寸与内容类型。商品发布前审核图片版权与被摄者同意。
6. **真实经营责任**：确认经营主体、支付渠道、物流退换货、客服、税务、隐私政策后才可启用订单。个人身份、残障情况、宗教信息不成为定价与消费判断条件。

## 建议分期
- **V1-A（本次）**：可操作的视觉和交互预览，零真实数据。
- **V1-B（须另经开发和验收）**：安全登录、独立数据库、可持久保存草稿、私密上传和审核流程。
- **V1-C（须另经经营审核）**：核实的商品实体、库存、前台同步、日志与订单/支付系统。

## 2026-11-24 商品资料 V1 对齐
已审定的八项商品信息及内部公平记录详见 `docs/manna-product-data-v1-20261124.md`。本交互原型新增独立规格与材质、现货/预售/售罄、发货地、配送范围、运费、销售主体、售后联系字段。当前仍是本地模拟录入，模拟经营主体和模拟来源均未核验；不能作为真实商品发布依据。
