# MANNA 买拿｜经营伦理与易彼益关系 V1（定稿）
日期：2026-11-24
状态：用户明确审核通过；理念与后续系统设计基线。非真实赠品活动条款或已上线的交易功能。

## 核心宣言（批准原文）

**买有所保，拿无所求。**

**交易有承诺，给予不求偿。**

## 事工发展关系（批准原文）

**买拿保留交易，同时实践给予；易彼益则进一步探索不以购买为前提的互助。**

## 两个动作，两种义务

### 「买」：交易有承诺

消费者买到的是明确、真实、可靠、合法的商品。商品质量、价格、交付、退换货、商户责任和法定权利不因额外赠予而减少。购买本身应当有独立的合理价值，不依赖赠品使其显得划算。

### 「拿」：给予不求偿

额外给予的目的不是提高中奖期待、诱导冲动消费、要求感谢或信仰回应，而是在正常交易之外实践慷慨。礼物的意义不由价格、稀缺性和偶然高价值所定义。受赠者不会因为获得礼物而承担额外购买、转发、献金或宗教参与义务。

「拿无所求」表达事工的给予伦理，**不表示可以取消对已经作出的赠品承诺的履约责任**；若对消费者承诺每单赠品，就必须按适用市场的规定清晰披露必要条件并履约。仅改为口头宣传，不会使促销承诺脱离监管。

## 不是盲盒游戏

MANNA 不把抽奖、中奖概率、大奖悬念、赠品估值排行榜、付费增加机会设计为首页或商城的消费刺激机制。是否引入随机赠品、每单是否必赠、类别和适用条件、库存与配送等，尚需另行设计并核验具体销售地的法律和税务要求；目前**不宣布已经确定的对外赠品机制**。

内部可以研究独立礼物库，但不得将赠品视作已审核通过或已可发放。礼物来源、所有权、库存、适用人群和质量安全、赠与同意、核算、运输成本和撤回退换处理，都需要留痕并经运营审核。涉及赞助或捐赠时，应与交易收入分账分类，不预先认定存在慈善扣税资格或募捐合法性。

## 从 MANNA 到易彼益

- MANNA：维持有保障的商品交易，在法定边界内练习给予与资源分享。
- 易彼益：探索不用由受助者购买就可以参与的互助，所需实际成本仍必须由某一可靠机制承担。
- 不把基督徒身份、残障情况或个人困境作为消费者必须接受的营销理由；尊重劳动、隐私、知情和自由选择。

## 工程影响

1. 已批准的八项商品资料字段继续有效，不因理念变化而删减商品质量和责任信息。
2. 「赠予」未来宜独立于商品 SKU、价格和库存系统，但**不能**绕开订单履约与合规审查。
3. 已公开的 MANNA 五重空间、使命与未开售提示保持原状；本文件只冻结理念，不授权自动开售、收款、宣传赠品规则或上线无鉴权后台。
4. 所有真实随机赠品与募捐/赞助机制，必须单独设计、法务核验和批准后才能部署。
