# 营火之地 · 事工内容维护手册

> 目标：让真实事工被看见，让同行者找得到可以参与的下一步。它不是机构广告墙，也不是一张永远不更新的宣传海报。

## 公开页与资料来源

- 公开页面：/yhzd.html
- 视觉系统：/campfire.css（只作用于营火页面）
- 数据渲染：/campfire.js
- 编辑资料：/data/campfire-content.json
- 未来活动：直接从现有 /routes.json 读取，仅显示未取消、日期不早于今天的 scheduled 活动；没有场次时显示诚实的空状态
- 自动检查：node --check campfire.js 与 node --test test/campfire-page.test.js

## 三类内容如何维护

1. **programs / 事工全景**：只列有对应公开入口、可持续承接参与者的主要事工。每条需要唯一 id、eyebrow、title、description、站内 href、行动文字 cta，可选 image、imageAlt。没有图时自动使用渐变与文字，不要为填满卡片使用无关照片。
2. **stories / 路上星火**：只选已在网站公开、有可核对资料、获得必要授权的真实事工。用人的处境与日常行动写故事，不拼规模、金额和效果数据，不做未经证实的成果承诺。所有故事都应指向对应的站内公开页面（当前指向 /lsxh.html）。
3. **voices / 同行回响**：短句、真实、匿名。取得公开展示所需授权后再发布；勿使用参与者姓名、孩子肖像、个人联系方式、具体健康状况等敏感细节。旧留言另存于 archivedVoices，策展时可以选择，但不应自动公开全部存档。

修改 JSON 后，请保留 version: 1，使用有效 JSON，且不要插入 HTML 代码。页面会以文本方式安全渲染。

## 图片与文案原则

- 图片采用已经获授权的真实生活影像，放在 /images/ 下。建议横向构图约 3:2 或 4:3，压缩后优先低于 350 KB。
- 文字避免使用“最大”“唯一”“已帮助多少人”等无法核实的效果结论；不把关怀服务写成消费广告。
- 如有未成年人或易受伤害群体的影像，应格外注意同意与隐私；没有合适授权时用物件、环境或无可辨识面容的画面。
- 对外联系方式优先用机构已经公开且确认适合接受咨询的渠道。当前“介绍事工”统一发往网站既有邮箱 hello@budao.org。
- 页面明确区分“项目介绍”“参与邀请”“同行见证”，不把参与者的个人表述当成机构认可。

## 发布流程

1. 在功能分支修改内容与图片，确认链接真实可达。
2. 运行 node --check campfire.js 和 node --test test/campfire-page.test.js。
3. 在 Vercel Preview 检查桌面与手机的文案、裁图、导航、分享、未来活动以及无活动时的状态。
4. 由负责同工核对所有合作机构名称、事实、图片/文字授权后，再合并进 main 发布。
5. 发布后检查正式页 https://budao.org/yhzd.html，并从首页入口访问一次。

## 后续可演进方向

- 为每个事工建立有分享摘要、真实照片、参与方式的独立详情页
- 建立简单的同工审核与内容发布工作流，避免任何未经审核的投稿自动公开
- 以匿名、聚合的方式了解访问到事工详情、联系与活动入口的转化，不收集访客个人轨迹

核心原则：**真实、克制、可参与、可持续。**
