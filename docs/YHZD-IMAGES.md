# 营火之地图片与漫游规则 V1

日常只需：把原始照片放进 `assets-src/yhzd/`，然后运行 `python3 scripts/build-yhzd-images.py`。

脚本自动校正方向、去除公开版本 EXIF/GPS、保持摄影者原始构图（只缩放、不裁切），并生成 480px / 960px WebP 与 `images/yhzd/manifest.json`。

页面原则：

- 图片池与文字池完全独立，不建立配对、caption、日期、地点或共同 ID。
- 桌面端是一片略宽于屏幕的可漫游夜色，而不是图库；没有箭头、分页点或“查看更多”。
- 画面两侧故意保留未完整出现的图文，暗示屏幕之外仍有内容。
- 图片和文字都只有极轻、极慢的空间漂移，避免明显动画感。
- 同一浏览器使用本地近期历史，连续刷新优先展示未见过的图片与文字；不使用 IP 识别。
- 一次加载只创建当前需要的少量 `<img>`，同页不重复；图片池再大也不会整池下载。
- 图片只按横/竖方向作为软偏好匹配 slot；如果近期未见图片不足，宁可换方向，也不强制重复或粗暴裁切。
- 480px 为基础版本；960px 存在时由 `srcset` 自动选择。
- 手机端 V1 暂不复制桌面横向漫游，优先保护原有文字阅读体验，后续单独设计。
- 当前 feature preview 暂用 120px 宽真实照片验证构图、随机与漫游；正式合并前必须由自动管线替换为 480/960 WebP，不能把低清预览资产作为生产版本。
