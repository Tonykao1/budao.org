# 2026-11-05｜网站整体框架与事工使命对话决议

## 已确定的全站框架

| 板块 | 已确定使命 | 边界 |
| --- | --- | --- |
| 步道 `test.html` | 步道事工的核心综述及参与实践，原定位不可改写 | 不是所有展示项目的总仓库 |
| 童行 `tongxing.html` | 胡子高讲绘本的流媒体式（网飞模式）内容 + AI 引擎；儿童及青少年收费营会、研学、青少步道 | 对外不以宗教标签呈现；未成年人安全、知情选择优先 |
| 同道 `tongdao.html` | 面向普世教会的事工宣传、带领人教学和模式传播，未来包括宣传视频、课程资料 | 不等于同工名录 |

| 营火之地 `yhzd.html` | **步道自身**的影像、评论、历史与事工展示 | 不收录外部社会服务机构目录 |
| 路上星火 `lsxh.html` | **具有基督信仰背景的社会事工与服务**的发现、展示、链接 | 不是营火之地的子栏目，亦非步道统一管理的项目 |

## 已确定的事工策略

- 「路上星火」**先发现，后整合**：当前从核实、展示、介绍、有效联系做起；未来再讨论支持、协作与跨教会资源连接。
- 「路上星火」不以非营利机构为唯一标准，但收录经营性服务时必须如实区分公益与商业。
- 外部主体保持独立性，收录不构成拥有、背书、管理或正式合作。
- 基督信仰构成价值根基，但不应成为社会服务的参与条件。

## 已决定的导航与设计

- 原主导航 **首页｜步道｜童行｜同道｜同工｜牧场** 保持不变。
- **否决**：在首页加大幅全新视觉专题、重做已有首页、把「路上星火」并入「营火之地」、把两者变成主从关系。
- **采纳**：两项并列于已有公共 Footer，首页与同工页均可直接访问，其他公共 Footer 保持一致；不要求同道、牧场等特殊页面强制加页脚。
- **正式名称**：保留「路上星火」。讨论过缩短为「星火」及改成「邻光」等，但没有批准更名。
- **视觉表现**：
  - `✦ 营火之地`：原有横向彩虹；
  - `❦ 路上星火`：竖向从下往上流动的彩虹；
  - 呼吸周期同为 **3.5 秒**，两者 **180°（1.75 秒）**错峰交替；
  - 竖向动画必须无缝循环，不得在颜色接缝处跳变。

## 暂不实施、未来再议

- 路上星火的独立域名、正式更名、项目审核工作流、在线捐赠或撮合平台。
- 童行的版权、AI 引擎实现方案、收费与未成年人保护的具体运营流程。
- 同道的课程标准、带领人训练与授权机制。
- 同工的后台权限和协作系统迭代。
- 牧场与易彼益的身份体系、治理和产品边界。
