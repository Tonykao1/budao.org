# BUDAO 六套海报 Canvas 信息排版规范（2026-11-23）

> 本规范基于“箭杆岭一线天小环线”六套真实输出样张，用于统一内容真实性与排版约束；不要求六套视觉风格趋同。

## 1. 六模板共享的内容合同

**第一优先级（不能丢失、不能无标记省略）**
- 路线全名：`title`
- 活动日期、星期、开始时间：`date/time`
- 集合地点：`meeting`
- 活动区域：`region`
- 路线距离、时长、难度与爬升：以真实记录为准
- 报名入口：唯一对应所选路线的二维码；已结束活动不能继续显示“报名中”

**第二优先级（数据存在时须合理呈现）**
- 适合人群 `suitable`
- 路面 `surface`
- 最低装备 `equipment`
- 探线限制、人数、目的：来自活动描述或将来独立的结构化字段，不得由模板编造

**第三优先级（允许明确缩略）**
- 活动说明的长段落，可展示带 `…` 的节选；同一句不得重复呈现
- 装饰性口号、设计纹样可以压缩，但不得挤压必需信息

## 2. Canvas 空间和文字约束

- 五张竖版：1080 × 1530；一张横版：1920 × 1080。使用逻辑像素定义布局。
- 必须为二维码、品牌标志、活动标题、日期地点建立固定的互不重叠保护区。
- 标题的实际包围盒必须在规定区域内；**文字旋转后需要验证变换后的矩形边界**。
- 必须先使用 `measureText` 检查单行宽度；能换行时先换行，再缩小字号；不能容纳时拒绝导出并提示字段，而不是强行挤到相邻区域。
- 竖版关键信息推荐 24–42px，次要说明不低于 18px；横版保持适合缩略预览的等效大小。此值是工程建议，不代替实际视觉回归检查。
- 正文应达到足够的视觉对比；在混杂照片上叠放文字时先设置局部明暗层，不得依赖单薄描边硬撑。
- 报名区在文字排布计算时，应扩展至少 20px 的安全缓冲带。
- 任何必填事实超出版面时，应 disable 导出按钮，返回如“集合地点过长，无法排入当前模板”的具体错误。

## 3. 语义防错

- 禁止模板硬编码“自由参与”“适合所有人”“不限人数”等承诺。
- 真实活动描述含“限5人”，就不能同时显示“自由参与”。更稳妥的普通二维码标题是“扫码报名”。
- `suitable` 说明受众，不等于报名状态；人数限制应从独立的结构化 `capacity` 等字段推导（字段正式接入前不能猜测）。
- 活动取消必须禁止报名海报；活动结束使用历史活动文案。
- 源数据缺失不允许自动臆造距离、路况、装备或人群。
- 原始二维码不得改写、重绘数据内容；任何版面修改均不得影响已有二维码绑定和原像素信息。

## 4. 本轮修复（Draft PR #137）

1. 逐梦动势：移除与人数限制矛盾的“自由参与”，压缩长标题横向预算。
2. 希望之径：长标题优先两行；消除活动说明重复；难度/装备按独立的二维码左侧窄栏多行排版。
3. 色彩引爆：增加活动目的说明的独立一行。
4. 光学预告：二维码迁移到右下独立信息区，避开完整标题与详情栏。
5. 东方盛典：样张未见同等级的硬遮挡，暂保留构图。
6. 远方召唤：品牌小标扩大；底部核心参数拆行，不再缩至 15px。
7. 公共 `posters-runtime`：超长摘要必须显示省略号。

## 5. 下一阶段（尚未实现）

为六套 Canvas 抽离共享 `PosterLayout` 层，实现：
- 事实数据 `PosterData`：同一个 schema，统一参与限制/状态。
- 测量层 `measure/wrap/fit`：中文标点、长地名、英文和多语种字形的可用性。
- 区域层 `reserve/overlap`：坐标矩形、旋转文字边界、二维码与标题互斥。
- 布局层 `compose`：每个风格保留自己的布局参数，但共享碰撞检测和降级策略。
- 验收层 `preflight`：绘制前/后验证，失败禁导出，统一错误提示。
- 回归层：长标题、超长集合地点、路线指标、装备清单、不同字体、已结束/取消、手机预览、Safari/Chrome、二维码识别等测试矩阵。

## 6. 发版门槛

- 测试与构建通过；不得只靠 JavaScript 语法检查。
- 六套海报分别使用至少三条极端样例产生实图，并检查 1080px 原图及 270px 宽手机预览。
- 零文字遮挡、零错误状态文案、零静默裁剪；二维码保持用户已验收的准确性。
- 未经视觉回归验收，不将本轮开发分支合并生产。
