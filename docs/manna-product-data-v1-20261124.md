# MANNA 商品资料 V1 · 正式数据标准

状态：**2026-11-24 已审核定稿，供下一阶段真实商品系统实施**  
适用：MANNA 买拿每件新商品、商品工作台、审核与公众商品展示。  
**这是数据合同，不代表真实商品数据库、运营后台、订单或支付系统已经启用。**

## 一、商品向消费者展示的八项信息（必须核验）

| # | 数据组 | 核心字段 | 对外位置 |
|---|---|---|---|
| 01 | 商品名称 | `name` | 卡片 / 详情 |
| 02 | 商品照片 | `images`，1–5 张，1 张主图 | 卡片 / 详情 |
| 03 | 一句话介绍 | `summary`，不超过 40 字 | 卡片 / 详情 |
| 04 | 规格与材质 | `specifications`（按品类动态定义） | 详情 |
| 05 | 售价 | `price.currency`、`price.amountMinor`，运费另列 | 卡片 / 详情 |
| 06 | 库存与状态 | `inventory.mode`、`inventory.quantity` | 卡片 / 详情 |
| 07 | 交付 | `delivery.origin`、`coverage`、`dispatchEstimate`、`shippingPolicy`、`shippingMinor` | 详情 |
| 08 | 售后责任 | `afterSales.sellerLegalName`、`policy`、`contact` | 详情 |

品类可以是织物、器皿、纸品等；衣物需尺码、器皿需容量、图书需版本/ISBN（如适用）。不可用无关字段凑满信息。采购价、供应证明、劳动报酬、审核意见及操作者身份**不属于**公开商品字段。

## 二、内部公平记录与审核

内部记录至少包括：
- `internal.supplierEvidenceRef`：可核验供货依据的私有引用；
- `internal.materialMinor`：采购与制作成本；
- `internal.laborMinor`：参与劳动报酬；
- `internal.fulfillmentMinor`：物流及支付成本；
- `internal.afterSalesReserveMinor`：售后责任预留；
- 服务端运营阶段还应具备来源核验人、经授权的成本证据和不可篡改的审核日志。
- 所有财务金额以**整数最小货币单位**记录；例如 CNY 128.00 存为 `12800` 分；JPY 按日元最小单位存整元；不得使用浮点数保存数据库金额。
- 经营余量 = 商品售价 − 已列成本与报酬。经营余量**不等于**净利润。真实运营还需考虑税费、损耗、退款与固定成本。

## 三、商品图片规范

主图建议 1:1，推荐 1600×1600 像素；另附 2–4 张细节图，允许原比例，不强制裁切主体。JPG / WebP 优先，PNG 用于必要透明图。用户上传的文件在工作台原型限制为每张 8 MB、最多 5 张；生产端必须再次校验文件头、尺寸、大小、版权授权并进行安全转码。管理人员上传后由服务器产生 **assetKey**，不是让录入同工填写图片 URL。单纯的本地 `blob:` 地址不得进入正式记录。

## 四、数据与审核流程

- 同工只需要在手机 / 电脑填表，不需要编写 JSON 或 Excel。
- 草稿允许字段缺省；**提交审核**时才强制执行完整性检查。
- 每次修改关键字段增加版本号 `version`；审核必须针对同版本快照 `approvedVersion`。
- 只有服务端验证身份与批准记录后才可把商品状态设为 `published`。不能信任浏览器端角色切换、隐藏字段或按钮状态。
- 对外数据只由 **字段白名单投影**生成，严禁直接序列化整个商品对象；不得向访客泄露成本、供应凭证、合作身份、隐私资料与审计记录。
- 销售主体、退换货政策、合法经营及支付渠道确认前，不启用真实交易或订单。

## 五、JSON 数据合同

详见 `manna/contracts/product-v1.js`，它是**纯验证和字段投影模块**，不会写入数据库、不具备后端 API、不会启用支付。生产服务端需基于这一合同另外实现鉴权、数据持久化及不可抵赖审核。

示例公开投影（所有数值为示意）：

```json
{
  "schemaVersion": "manna.product.v1",
  "id": "example-001",
  "sku": "MANNA-001",
  "name": "收纳织物",
  "summary": "便于日常收纳和随行携带。",
  "category": "织物与收纳",
  "specifications": {"material": "待真实核验"},
  "images": [{"assetKey": "example/image-key", "alt": "正面照片", "position": 0, "primary": true}],
  "price": {"currency": "CNY", "amountMinor": 12800},
  "inventory": {"mode": "in_stock", "quantity": 12},
  "delivery": {
    "origin": "需真实确认的发货地",
    "coverage": "需真实确认的配送范围",
    "dispatchEstimate": "需真实确认的发货时间",
    "shippingPolicy": "需真实确认的运费规则",
    "shippingMinor": 0
  },
  "afterSales": {
    "sellerLegalName": "需正式核验的经营主体",
    "policy": "需正式核验的退换货规则",
    "contact": "需正式提供的售后联系方式"
  }
}
```

**上例仅说明数据形态，绝不代表上述商品或任何供应方已经通过核验、可以发布销售。**

## 六、展示层级（不增加解释性商业宣传）

- 商品卡：主图、名称、≤40 字简介、售价、库存状态；
- 详情页：规格材质、多图、交付费用、售后责任；
- 内部工作台：供应证据、成本、岗位劳动报酬、审核记录与凭证，仅授权人员可见。

已经定稿的原则：**商品卡极简，商品详情完整，管理后台严谨。** 所有新增字段必须能解释其业务或合规必要性，不能用身份和信仰内容替代商品本身的价值。
