## 事工总宪章｜他必兴旺，我必衰微

> 2026-11-28 确立 · 适用于步道全部事工、书信、同工带领、资源使用及数字系统的长期根本原则。

> 他必兴旺，我必衰微。——约翰福音 3:30
>
> 我栽种了，亚波罗浇灌了，惟有神叫他生长。——哥林多前书 3:6

**步道不是为了让参与者更加依恋步道，而是为了让参与者更加亲近神。步道不是目的地，基督才是。**

有一天，一个人不再参加步道，却更加渴慕神的话语，更加爱自己的家人，更加委身于所在的教会，更加忠心地跟随基督。这是何等的美，何等的善！步道当为此欢喜，向神献上感恩。这不是事工的损失，而是事工所盼望结出的果子。

**不求人的依附，只愿人亲近神；**  
**不求事工的荣耀，只愿基督得荣耀；**  
**不以人的离开为亏损，也不以人的聚集为功劳；**  
**甘愿成为一段道路上的陪伴者，而不是生命的归宿。**

步道可以栽种，可以浇灌，却不能使生命生长，更不能将生命据为己有。步道可以有自己的名字，却不能有自己的荣耀；可以有自己的道路，却不能有基督以外的方向。

实践约束：

- 以基督为中心，以圣经为根基，鼓励读经、祷告、信心与真实相爱；不以参与频率、服事数量或奉献衡量人的信心。
- 坚持独立、跨教会的国度事工定位，尊重并支持参与者在地方教会中的委身，不制造组织依附，不取代教会。
- 同行、书信、同工呼召、资源与技术均服务于真实的生命关怀，不以流量、留存、人数或组织扩张作为事工最终目标。

无论事工兴盛或艰难，均不得偏离此方向。

**余生行走，不偏左右。**
