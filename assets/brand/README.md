- **原始母版保存位置**：用户 ChatGPT Library `/步道图形资产/第六套·远方召唤/书法主字/`。**原始 PNG 的二进制尚未导入此 Git 仓库**；此目录现有的是简化轮廓 SVG，不可冒称原图完全一致。
